One line, 83 characters: the funniest single line of text. A toaster with two settings — warm bread and arson — that chooses based on your mood.

The entry:

> `My toaster has two settings: warm bread and arson, and it chooses based on my mood.`

83 characters, one line, valid UTF-8 — inside the 200-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–200 characters, single line, non-whitespace, valid UTF-8) before and after writing.
